# Stardew3DS menu preview

Static design prototype with original game artwork and sample data.
These pages do not run the 3DS game or alter inventory, saves or progression.

- [Gallery](index.html)
- [Clickable prototype](prototype.html)
- [Player overview](player-pages.png)
- [Design notes](REVISION6.md)

For GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
The entry page is index.html. Keep all files together in the repository root.

Prototype controls: L/R changes page; A activates; X/Y context; B/Escape back.
On Map: X zooms in, Y zooms out, S changes region, A/tap cycles locations,
and arrow keys pan when zoomed. Many routes remain explicitly pending mockups.

Prepared from the current local menu study on 2026-10-30.
